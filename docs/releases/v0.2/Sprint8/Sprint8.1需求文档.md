# 范围

在图表页执行内置策略后，能在主图看到买卖点标记，并能用列表五按钮复盘：当前行强调、主图对该根 K 线整列铺背景高亮。

依赖 Sprint8 已落地的 `strategy.run` 返回值（`series.buy_signal` / `sell_signal`）与平级策略面板四 Tab 列表。

# 功能

## 1. 列表复盘（所有 Tab 的公共操作）

目的：在当前 Tab 的数据列表里切换选中的 K 线，并在主图高亮，从而复盘。

由左到右五个图标按钮：

1. **上一根 K 线**：切到列表中上一条。未开始，或已在第一根时不可用。
2. **刷新**：回到第一根。未开始时不可用。
3. **开始**：进入复盘模式，选中第一条数据，图表进入高亮模式。点击后该按钮变为「取消」。
4. **取消**：退出复盘模式，图表退出高亮。点击后该按钮变回「开始」。买卖点标记保留。
5. **下一根 K 线**：切到列表中下一条。未开始，或已在最后一根时不可用。

列表：

- 默认纯列表；复盘中选中行用背景色强调。
- 除按钮外支持直接点击选中（仅复盘中）。
- 按钮切到可视区外的行时，滚动条保证该行出现在可视区**底部**。
- 索引绑定当前 Tab 过滤后的列表，不是全量 `series`。
- 当前 Tab 无数据时，「开始」不可用。

## 2. 主图买卖点标记

- 策略「执行」返回结果后：买点 K 线下方红色图标，卖点 K 线下方绿色图标。
- 图表组件需要加入标记支持。本轮 `sell_signal` 仍恒为 false，卖点标记允许一张都没有。
- 关面板、切策略、清空结果、换标的 / 换复权后，标记消失。

## 3. 复盘高亮

- 开始复盘后图表进入高亮：被选中 K 线以该根宽度铺满主图整个高度。
- 高亮不得压过 K 线。颜色：买点浅红色、卖点浅绿色、非买卖点浅灰色。
- 取消复盘或关面板后，图表一并退出高亮。
- 选中 K 线若不在当前可见区，主图滚到该根可见（否则高亮无法点验）。

# 验收

- 五按钮可用/禁用符合位置；开始后当前行强调、可点选；切到可视区外时该行滚到列表底部；取消后回到纯列表
- 执行成功后买点下方红色、卖点下方绿色；关面板或清空结果后标记消失
- 开始复盘后选中 K 线整列铺背景；取消复盘或关面板时图表退出高亮
- `MingSystemVer1` 在图表页能走完「执行 → 标记 → 复盘高亮 → 取消 / 关面板」闭环
