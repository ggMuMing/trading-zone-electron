# 需求概述
## 1.使用脚本编辑器创建策略
- 当前现有指标系统，在前端的脚本编辑器中编写脚本，到python解析和后端保存为指标，最终可以在图标上展示。
- 本迭代计划实现策略系统，在前端用和指标相同的方式，使用脚本编辑器编写策略脚本，后端解析+保存，并接入已经存在的策略功能。
- 当前系统内置了`MingSystemVer1`和`MingSystemVer1`两个策略类，新设计策略也延续这两个类的结构，策略的最终目标是生成买卖点
- 文本编辑器可以和指标共用，区别在于接口类的不同。
- 创建策略也应参考`商流链`模型，做到模块的解耦和逻辑通顺
- 注意不同点，指标的变量通过内置的input实现，策略的可调变量通过`declared_default`函数定义，解析起来亦有区别，这里我暂时没有思路:是否需要调整策略类，引入指标类的input?
