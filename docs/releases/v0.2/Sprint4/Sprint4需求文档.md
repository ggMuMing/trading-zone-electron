# 二、新加功能
## 1. 数据提取
- 从tushare获取数据入库
- 更新数据加入上列数据的获取
- 创建相应接口向前端提供数据获取

## 2.创建新的页面——仪表盘。
- 仪表盘页面设为主页
- 仪表盘采用四宫格布局
  - 左上方：`大盘指数的当前数据+宽基指数的当前数据`数据列表
  - 右上方：日线级别K线图，与左上方联动，显示当前选择的指数
  - 左下方：统计数据
    - 两融余额+较上一交易日两融余额变化+两融余额的历史曲线图+历史变化柱状图。曲线图占据一个窗格，包括两融余额曲线和上证指数收盘价的曲线；历史变化图的窗格再曲线图下方，根据历史数据计算，余额减少在零轴下方用绿色柱状图标识，余额增加在零轴上方用红色柱状图标识。
    - 护深京三市总成交额+较上一交易日成交额变化+总成交额曲线图+历史变化柱状图。曲线图和柱状图和两融余额一样分成两个窗格。计算方法也相同。
    - 涨跌家数统计。展示四个统计数据：上涨家数、涨停家数、下跌家数、跌停家数。绘制一个直方图用来展示涨跌比例的分布图。不显示纵坐标，横坐标从左到右：涨停、涨停~5%、5%~1%、1%~0%、平盘、0%~-1%、-1%~-5%、-5%~跌停、跌停。上涨区间采用左闭右开，下跌区间采用左开右闭。
  - 右下方暂时空着。
