创建策略的时候定义了参数。本迭代在前端调用策略前，于策略面板里指定这些参数的值，再生成买卖点结果，从而在前端调参。

调参发生在调用之前，结果由同一次执行产生。改输入框本身不重算；只有再次执行才生成新的买卖点。

# 现状

策略和面板之间只有标的、区间、复权。算法参数停在 Python 类属性上，列表接口也不告诉前端有哪些参数。

`MingSystemVer1` 当前写死的是：

| 代码字段 | 含义 | 代码缺省 | 说明文档缺省 |
|---|---|---|---|
| `squeeze_period` | 标准差 / ATR 周期 | 20 | 文档「参数管理」未列 |
| `wr_n` | 过去 n 日波幅 | 3 | 6 |
| `range_mode` | 信号 K 波幅：`co`（收−开）或 `cl`（收−低） | `co` | C-O 或 C-L |
| `k` | 波幅系数 | 0.6 | 0.6 |
| `vol_x` | 成交量均线天数 | 5 | 5 |
| `vol_y` | 成交倍量 | 1 | 1.5 |

构造函数只收 `ts_code`、`start_date`、`end_date`、`adjust`。`strategy.run` 的契约同样只有这四项加 `strategy_id`。`strategy.list` 只返回 `id` 和 `name`。面板配置区只有起止日期和执行按钮，执行请求不会带算法参数。

说明文档里的止损系数 `z`、止盈系数 `w` 没有进入计算。卖点列目前恒为否。本轮调的是已经参与买点计算的参数；把未实现的卖出规则做成表单项，改了也不会出卖点。

面板缺省值以代码里正在跑的值为准（`wr_n=3`、`vol_y=1`）。文档里的 6 和 1.5 与实现不一致，不能直接当界面缺省。

指标侧已有可参考的形态：声明出名称、标题、类型、缺省、上下界，设置弹框按声明画表单，计算时把值传回去。策略没有这套声明，而且 `range_mode` 是二选一，现有指标控件只有整数、小数、布尔，盖不住。

# 使用路径

1. 在「指标与策略」里选中策略，右侧打开策略面板。
2. 配置区除起止日期外，出现该策略声明的参数，控件里已是缺省值。
3. 改若干项，点现有的执行按钮。
4. 统计、买点 / 卖点 / 混合 / 自选列表、主图买卖标记，全部换成这组参数的结果。
5. 再改参数但不执行，屏幕上仍是上一次执行的结果。
6. 换一只股票或改日期区间，已填的参数保留；换成另一条策略，面板按新策略的声明和缺省重新出现。

同一标的、同一区间、同一复权，只改一个参数再执行，买点数量或买点日期应与缺省跑出来的不同。把参数改回缺省再执行，应与今天不传参数的结果一致。

# 功能

## 1. 策略在创建时声明参数

每项至少要有：字段名、中文标题、类型、缺省值。类型至少覆盖整数、小数，以及 `co` / `cl` 这种枚举。需要约束的项带最小值、最大值。声明跟策略类走，前端只按声明画，不把 `MingSystemVer1` 的字段名写进面板。

`MingSystemVer1` 本轮要暴露的就是上表六项。`squeeze_period` 已经参与挤压滤网，一并可调。`z`、`w` 不进本轮。

枚举在界面上是两个选项「收−开 / 收−低」，对应现有 `co` / `cl`。不让使用者手填这两个内部代号。

## 2. 前端在执行前拿得到这份声明

列表现在只有 `id`、`name`，面板无从画控件。列表（或等价的读取）要带上参数声明。打开面板时用缺省填表。某策略没有可调参数时，配置区保持今天的日期加执行，不留空表单。

## 3. 执行请求带上使用者填的值

`strategy.run` 增加参数对象。未传的项用策略缺省。未知字段、类型不对、超出上下界、枚举值不在允许列表里，拒绝执行并在面板上显示错误，不拿缺省悄悄重跑。

策略实例必须读这次传入的值。只改请求、类属性仍写死，面板上的修改不会影响买卖点。

## 4. 结果仍走现有买卖点通路

成功返回后，统计、四个 Tab、复盘高亮、主图标记的更新方式不变。执行中日期和参数控件不可用。参数非法时不发请求，提示方式与「起始日不能晚于结束日」同一层级。

参数表单落在策略面板的「配置」段里，和日期、执行按钮放在一起。长中文名在窄面板里要能对齐。

# 本轮不做

- 在界面里新建策略，或把调过的参数存成方案、写入数据库。关掉面板或重开应用后回到声明缺省。
- 改一个数字就自动重跑，或做参数扫描、网格寻优。
- 补止损、止盈算法，或为了调参去改滤网公式。
- 改复盘、列表列选择、图表高亮的交互。
- 把 Sprint9.1 里 Tabs 样式、统计行位置、三段分割线一并做完。

# 验收

- 打开 `MingSystemVer1` 面板时，配置区出现六项参数，缺省为代码当前值（含 `wr_n=3`、`vol_y=1`），波幅范围是「收−开 / 收−低」二选一
- 同一标的、同一区间、同一复权，只改一个参数再执行，买点数量或买点日期与缺省执行不同
- 改回缺省再执行，与不传参数的结果一致
- 改参数后不点执行，统计、列表、主图仍是上一次执行的结果
- 非法值（类型不对、越界、未知字段）不发请求，面板上有错误提示
- 执行中参数与日期不可改；无参数声明的策略仍只有日期和执行按钮
