## 价格口径

个股与宽基必须分开处理，不能都读未复权 `close`。

- 宽基指数：`index_daily` 的开高低收、成交量，不复权。
- 个股：`daily_bar` + `adj_factor`，缺省前复权（qfq）。`scale = 当日 adj_factor / 该股最新 adj_factor`；开、高、低、收乘 scale；成交量不复权；缺因子当日 scale=1。
- 所有用到 CLOSE / OHLC 的因子（STD20、ATR、布林、肯特那、威廉）都走上述价格。终端元信息写明：指数不复权 / 个股前复权。

## STD20大类 · `percentile` · STD20历史分位数

输入：该标的全部交易日 `close`（个股为前复权收盘，宽基为不复权收盘）。

- `MA20`：收盘的 20 周期简单移动平均
- `STD20`：收盘在最近 20 个交易日的总体标准差（`ddof=0`）
- `CV20 = STD20 / MA20`
- `PERCENT`：当前 `STD20` 在该标的全部有效 `STD20` 中的经验分位，范围 0–100，定义为小于等于当前值的样本占比。打印元信息时写明该定义

打印（先 STD20，空一行，再 CV20）：

- 中位数、均值、最小值、最大值
- 分位数表：P5、P10、P25、P50、P75、P90、P95

图：STD20 分位数表、CV20 分位数表各一条折线，存 png。

csv 列：`trade_date, close, ma20, std20, cv20, percent`。

## STD20大类 · `distribution` · STD20分布

对象四个序列：`STD20`、`CV20`、`log(STD20)`、`log(CV20)`。`log` 为自然对数；非正值丢弃并在元信息写明丢弃条数。

打印一张表，列至少包含：序列、偏度、均值、中位数、峰度。偏度、峰度用 pandas 默认（超额峰度）。

图：四个序列各一张直方图 png。

非重叠样本：在有效值序列上从第一根起每 20 个交易日留 1 个点。对该样本做 Jarque-Bera、D'Agostino K²、Shapiro-Wilk。终端一张表：序列、检验名、统计量、p 值、样本量。Shapiro-Wilk 样本超过实现上限时，打印跳过原因，不截断假装全样本。

本步骤无单独字段说明：上述两张统计表各导出一个 csv。

## 波动压缩因子研究 · `bb_inside_keltner`

策略里的压缩条件在 `C=2` 时化为 `STD < ATR`。本条目按因子研究原文：

- 压缩日：`STD20 < ATR20`
- `ATR20`：Wilder ATR，周期 20。文档未写平滑方式，打印元信息标明 Wilder

压缩区间：连续压缩日合并为一段。

打印并导出：

- 区间条数
- 长度的中位数、均值、方差（样本方差 `ddof=1`）、偏度、峰度
- 长度序列的 Jarque-Bera、D'Agostino K²、Shapiro-Wilk（长度样本不足该检验下限时打印跳过原因）
- 长度分位数表：P5、P10、P25、P50、P75、P90、P95。因子研究未写插值方式，打印元信息标明 pandas `quantile` 线性插值

图：

- 长度分位折线：与分位数表同一组 P5–P95，png
- 长度直方图：按整数交易日分箱，柱心对齐到长度。样本为 0 时不画图，打印跳过原因

另导出区间明细 csv：`start_date, end_date, length`。

### 突破肯特那通道

同一 2 级下的分节，不进菜单。通道用策略缺省 `C=2`：`MA20 ± 2 * ATR20`。因子研究未写突破用哪根价格，打印元信息标明收盘价。

- 通道内：收盘严格介于下轨与上轨之间
- 突破：收盘严格高于上轨（向上）或严格低于下轨（向下）
- 节点：先出现「压缩日且收盘在通道内」，其后第一根突破 K 线。记完一次后，必须再次出现「压缩日且收盘在通道内」才记下一个节点
- 对数收益：`ln(close[t+h] / close[t])`，`t` 为突破日，`h` 为 1、3、5、10、20 个交易日。末端不足或价格非正记为缺失，不外推

纵向：每个周期把全部节点的对数收益排成一列，向上与向下不分开。

- 均值、中位数、样本方差（`ddof=1`）、累加收益率（该列有效对数收益之和）
- 偏度、超额峰度、Jarque-Bera、D'Agostino K²、Shapiro-Wilk
- 分位数表：P5、P10、P25、P50、P75、P90、P95，线性插值
- 图：五个周期画在同一张分位折线上；直方图每个周期一块，分箱数 `max(10, floor(sqrt(n)))`。样本少于 2 不绘制该块

- 斯皮尔曼相关：同一突破节点上五个周期的对数收益，成对删除缺失；`scipy.stats.spearmanr`；样本量低于 3 跳过。终端打印相关系数矩阵与 p 值矩阵；成对明细 csv：`周期A, 周期B, 斯皮尔曼系数, p值, 样本量, 说明`

对数收益打印 6 位小数，偏度和峰度 4 位；斯皮尔曼系数 4 位。

## 威廉指标下穿50事件研究 · `expected_return` · 下穿50后预期收益

源文：`2.变量研究.md` 第 3 节。策略缺省 `N=10`。

威廉指标用通达信/东财 0–100 公式，不用 -100–0 的 Williams %R：

- `WR = 100 * (HHV(high, N) - close) / (HHV(high, N) - LLV(low, N))`
- 窗口含当日。`HHV = LLV` 时记缺失，不参与下穿，并打印条数
- `WR < 50` 等价于收盘位于 N 日波幅上半区

信号 K：上一根 `WR > 50` 且当前 `WR < 50`。等于 50 不算下穿。

收益为简单收益率，不是对数收益：

- `R_t0 = close[t] / close[t-1] - 1`（信号日相对前收；说明只把 t1/t5/t10/t20 定义为从 t0 起算）
- `R_th = close[t+h] / close[t] - 1`，`h` 为 1、5、10、20。原稿表头 `R_t2` 按说明中的 t20 写成 `R_t20`
- 末端不足或价格非正记空，不外推

同一张 csv：每个信号一行，其后固定六行统计。列：`日期&统计, R_t0, R_t1, R_t5, R_t10, R_t20`。

统计按列、只对有效收益：

- 样本数
- 均值、中位数
- 胜率：大于 0 的占比
- 标准差：样本标准差 `ddof=1`；少于 2 个记样本不足
- 累加收益率：该列有效简单收益率之和

终端用同一张表，删掉全部信号行，只留这六行统计。收益率 6 位小数，胜率 4 位。不画图。

对照组用同一收益定义和同一张统计表，不进菜单。`WR = 50` 两边都不进。

- 主对照：当日 `WR > 50`。csv 后缀 `_above50`
- 参考组：当日 `WR < 50` 且不是信号 K。csv 后缀 `_below50`

两组 csv 都含全部样本行和六行统计。终端只打印六行统计。

## 混合变量研究 · `expected_return` · 混合买入后预期收益

源文：`2.变量研究.md` 第 4 节。只做买入，卖出不实现。缺省 `M=20`，`C=2`，`N=10`，`W=5`，`K1=0.6`，`R=5`，`K2=1.2`。

同一根可判定 K 线上四条同时成立：

- 波动坍缩：`STD20 < ATR20`（`2*STD < C*ATR` 且 `C=2`）。STD20 为收盘总体标准差 `ddof=0`。ATR20 为 Wilder，与波动压缩条目同一实现
- 长周期：`WR10 < 50`，通达信/东财 0–100。这是状态，不是下穿
- 短周期：`high_W`、`low_W` 含当日。`C-O` 与 `C-L` 两套都算，打印分节，不拆菜单
- 放量：`vol >= MAV5 * 1.2`，MAV 为含当日的简单均量，成交量不复权
- 坍缩、威廉用严格小于；强 K、放量用大于等于

可判定：STD、ATR、WR、W 日波幅、开高低收、成交量和均量都有效。无效日不进信号，也不进对照。

信号 K：上一根可判定且四条不同时成立，当前根四条同时成立。

收益、统计、打印与第 3 节相同。`C-O`、`C-L` 各一套信号、主对照、参考组。

- 主对照：当日可判定，且四条不同时成立。csv 后缀 `_co_outside` / `_cl_outside`
- 参考组：当日四条同时成立，且不是信号 K。csv 后缀 `_co_inside` / `_cl_inside`
- 信号 csv 后缀 `_co` / `_cl`

全股票汇总是 `pool_mix_entry.py`，直接执行，不进菜单。股票库与 `daily_bar` 都有的个股，各自前复权后套用本节，样本合成一列。保留信号和主对照，不计算参考组。每条信号、每个主对照交易日各算一条。主对照 csv 只写六行统计。
