# 1.分组系统开发
## 概述
- 分组系统服务于自定义标的分组功能。允许用户管理分组，以及管理分组中的标的。
- 分组功能分为三层，最外层是`分组分类`,作为“分组的分组”,是保存分组的“文件夹”。第二层是分组，分组是一组标的的集合。第三层是分组中的标的。
- 分组系统涉及应用的几个部分
  - 分类。当前应用已经有三大内置分类：指数行情、成分股、行业，`分组分类`和这三大类同级别，即每创建一个新的分组分类，在指数行情、成分股、行业下面就会多出一个分类。注意：分组分类和内置分类是分开管理的，不能混淆，但是逻辑是相同的。
  - 图表页和图表。图表页中的标的列表基于上述的分类。图表预留了分组的按钮位置，暂时是不可用的，放开后，允许直接将个股加入已经创建好的分组。
  - 选股功能。按日期+策略选股后，选出的标的可以按照日期+策略保存为一个分组。
  - 模拟盘。创建模板，单个标的、一组标的二选一的基础上，加入新的选项分组标的，直接加载整个分组的标的。

## 详情
### 1.根据三层结构设计数据表
- 分组可以不加入分组分类中，在删除分组分类的时候，是删除表中的关联关系，分组的分组分类为空的时候，代表这个分组未分类。`未分类`需要作为不在分类表中的特殊情况处理。
- 分组分类和分类皆支持修改名称，所以名称不能作为ID设计。

### 2.创建分类管理对话框
- 侧边导航栏加入分类管理入口，点击是一个弹框，而非页面
- 分类管理弹框由两部分组成。左侧是分组分类+分组组成的目录树，右侧是选择的树节点的管理功能页
- 左侧目录树细分为两个区域，上部一小片区域为功能区。下部大片区域为目录树。
  - 功能区包括`创建分类`、`创建分组`、`修改名称`、`删除`
  - 目录树缺省为一个`未分类`节点，该节点不支持增删改。未指定分类的分组都放在这个节点下。
  - 每创建一个分类就在树上加入一个分类节点。创建的分组节点是分类节点的子节点。
  - 分组和分类的选中效果有区别。分组被选中后，切换右侧的内容到该分组，分类选中后切换右侧内容。分类节点只支持在左侧的功能栏提供的功能。所有右侧内容对应的被选中的分组节点和左侧要使用功能被选中，两个要区分。
- 右侧内容页对应左侧选中的分组。内容包含两部分：功能区和标的列表。功能区包括标的选择器，批量操作按钮、删除按钮。列表只显示标的名称、列表支持批量选择。

### 3.给标的指定分组
- 开放图表上的分组按钮，点击按钮显示弹框，弹框是支持多选的分类+分组的树，支持一次分配到多个组。弹框内还需要一个分组名称过滤器。保存时提示选择了哪几个分组。

### 4.模拟盘模板加入分组标的
- 模拟盘模板加入分组标的，分组标的下两个控件：`隐藏标的名称和代码`的checkbox,一个标的列表框，可以删除一些标的缩减模拟时的标的池

### 5.选股保存分组
- 执行选股得到结果后，允许保存成一个分组，名称自动使用`时间_策略名`，选择分类，需要支持设置分类为默认。
