# 1.统计格

- 现有「涨跌家数」四数（上涨 / 涨停 / 下跌 / 跌停）和九档直方图保持不变，仍展示**最新有涨跌状态的交易日**。
- 在九档直方图**下方**新加一张图：涨停家数、跌停家数两条历史曲线。
- 曲线日期窗口与两融 / 成交额一致（看板查询的 `start_date`–`end_date`，默认 `20240101` 至今天）。
- 图例用色线 + 描述：涨停（红）、跌停（绿）。

# 2.数据

- 不新拉 Tushare 接口。涨跌停状态继续用已入库的 `stock_limit_status`，过滤规则与当日四数相同（与 `daily_bar` 同日 JOIN，且 `vol > 0`）。
- 「更新数据」已会把 `limit_status` 按日写入；本迭代不改同步路径。
- 不做盘中实时涨跌停，不做上涨/下跌历史曲线，九档不画成历史曲线。
