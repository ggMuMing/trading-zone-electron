# 回放功能
## 概述
- 在图表页面加入K线回放功能，用于复盘和练习。
- 回放功能是截断K线，从某个起始点开始添加/播放K线。

## 功能详情
### 1.回放入口
- 在跳转按钮右侧加入`回放`按钮
<!-- - 点击`回放`按钮，在右侧打开`回放面板`（同策略面板）（放弃方案） -->
- 点击`回放`按钮，弹出小下拉框，里面包含`回放配置`的配置内容

### 2.`回放配置`布局：
从上到下：
- 选择开始时间
  - 两个checkbox：随机时间、固定时间。
  - 选择固定时间：下方单独一行显示时间选择器
<!-- - 操作面板（放弃方案）
  - 终止按钮，只有在开始之后才可用（移除和暂停按钮合并）
  - 开始图标，开始之后变为终止按钮
  - 下一根K线图标，开始之后才可用
  - 居中，图标放大 -->
- 开始按钮（文字按钮）

### 3.回放交互
- 点击开始回放按钮后，启动回放模式
- 点击开始回放按钮后，在回放按钮右侧加入终止按钮和下一根K线按钮。点击终止按钮两个新增按钮消失，代表退出回放模式
- 点击开始回放按钮后，根据随机时间生成的截止时间或者指定的时间，K线图的时间序列截断到截止时间。
- 点击下一根K线，在时间序列上增加一个单位，下一根不应触发重算，而是在初始计算完成后，直接增加
- 开始回放后，计算指标、计算复权需要遵循时间序列的长度
- 开始回放后，禁用跳转按钮、禁用选择策略（可以操作指标）、禁用切换周期按钮
- 开始回放期间，切换标的，全量计算标的数据，但是显示根据当前的时间序列显示


# 模拟盘功能
## 概述
- 加入模拟盘功能，支持前端页面模拟盘交易，支持前后端的模拟盘交易记录管理
- 侧边导航栏加入新的页面`模拟盘`
- 模拟盘功能包括自顶向下包括：逐K交易、资金管理、交易成本设置、模拟交易断点延续、交易账户管理、交易记录管理、交易记录分析

## 功能详情
- Part1
  - 侧边导航栏添加`模拟盘`页面入口
  - `模拟盘`页面采用三列布局，左侧两列和`图表`页面相同的两列布局，右侧是`图表`页中的策略面板同款。
- Part2
  - 左边列表保留标的列表，去除`标的范围`选择器和过滤搜索输入框。标的列表用于后续在模拟盘配置完毕后，显示选中的标的列表，不全量显示。当下只保留000001.SZ平安银行作为占位
  - 中间图表菜单栏移除：分组、跳转、回放、右侧的面包屑导航
- Part3：模拟盘表单+模拟盘方案管理
  - 模拟盘表单由下列构成：
    - 模拟开始时间：随机/固定日期（和回放功能类似）、随机时间是否隐藏时间
    - 标的选择：单个标的/一组n个标的（n小于等于10）、指定单个标的/指定一组标的、随机单个标的/随机一组标的、随机标的是否隐藏标的名称和代码
    - 交易设置：总资金、印花税、手续费
  - 每一个模拟盘方案对应一个模拟盘表单，支持方案的增删改查
  - 方案是一个模板，每次加载一个方案是将这个模板复制到当前表单上
- Part4：模拟盘面板加入Tabs
  - 模拟盘表单作为缺省第一个tab,命名为模板。移除原来的标题栏，两个图标放在和`模拟开始时间`标题同行
  - tab2是交易
  - tab3是交易记录
- Part5：模拟盘页面引入回放系统
  - 模拟盘页面的图表引入图表页面同款的回放功能。区别在于没有`回放`按钮，取而代之的是开始终止按钮。先实现开始终止下一根功能，时间从定从2025年开始
  - 下一根常驻工具栏，未开始时不可用
- Part6：交易Tab
  - 前提：交易Tab的表单样式和模拟盘对齐
  - 将交易Tab和模拟Tab交换位置
  - 交易Tab加入模板选择器，缺省为模板缺省
  - 将模板信息以字符串形式展示，模板信息和模板选择器用横线隔开
  - 加入资金管理part，里面包括总资产、证券市值、持仓盈亏、可用资金4个字段
- Part7：交易操作，从上到下
  - 交易标的输入框（默认为空，括号了的内容不显示）
  - 分出两列
    - 左列
      - 买入价格+一键设置开盘价/收盘价
      - 买入数量
      - 可买{x}股（x由可用资金和价格计算得出，括号里的内容不显示）
      - 买入按钮
    - 右列
      - 卖出价格+一键设置开盘价/收盘价
      - 卖出数量
      - 可卖{y}股（y是已买入的股数）
      - 卖出按钮
  - 加入T+1的判断，当日买入的股数，当天不能卖。持有大于1天的股份可以买卖
- Part8：加入本次模拟盘交易记录表
  - 表由5列组成：时间、名称/代码、方向、价格/数量、金额
  - 方向分为买入、卖出，买入用红色，卖出用绿色
- Part9：交易和图表的交互
  - 初次进入模拟盘页面，删除默认的000001，图表和标的列表都为空
  - 在交易tab的模板标题上方再加入一个part，里面是三个按钮，采用三列布局
    - `开始交易`，移除图表工具栏的开始按钮。开始交易后，按钮变为红色`结束交易`按钮。点击`结束交易`后，结束交易，并且切换回`开始交易`,记录截止时间，可以断点继续交易。
    - `归档交易`，默认不可点击，在点击结束交易这一步走完后，归档交易可以点击，开始交易后不可点击。功能后续补充，当前不做。
    - `重置交易`，在交易未开始状态下重置到初始化状态
  - 点击开始交易，图表进入回放模式，并根据当前交易tab中的模板方案，依次：
    - 加载标的：
      - 单个/一组
      - 指定/随机
      - 隐藏标的：这里隐藏需要在页面隐藏标的代码名称这些信息，所以使用大写英文字母代替、注意图表工具栏的名称位置也需要隐藏信息，改为大写字母
    - 加载时间：
      - 固定时间
      - 随机事件
      - 隐藏时间：这里需要图表隐藏时间轴、主图的价格图例也需要隐藏。
