v0.3.11需求文档
___

本迭代用于改进需求

# 1.模拟盘页面改进
- 买入数量和卖出数量的加减按钮目前步进为1，但是数量最小1手为100股，所以步进改为100
- 调整持仓成本和持仓盈亏的计算逻辑。现在持仓盈亏随卖掉股数一起减值，改为只要还有持仓，盈亏统一归于剩余持仓的成本，基于此计算持仓成本。即卖掉股票但还有持仓，不减持仓盈亏，重新计算持仓成本。直到清仓。基于这个逻辑重新组织计算算法
- 基于上述逻辑算计的成本在模拟盘的图表上绘制成本线，用灰色2px虚线绘制，并在直线右下角显示持仓成本
- 加入条件限价单功能。即在未到达的位置设置条件现价单，如果未来股价达到这个位置，自动成交。在交易part的右上角加一个`条件单`的图标按钮，点击显示弹框，在里面加入条件单设置和条件单列表。条件单设置包括，限价、数量、持续时间。创建的条件单需要加入当前的那根K线时间；条件单逾期作废。条件单列表包括创建时间、限价、数量、持续时间和条件单状态。
- 条件单弹框改为可以拖拽移动位置
- 在条件单页面加一个显示在图表的开关。打开后，在图表的限价位置显示天蓝色的限价虚线
- 弹框中的`显示在图表`开关放在条件单标题右侧；
- 没有开始交易时，条件单不可用；
- 条件单需要加入标的这个变量，不同标的对应不同的条件单
- 当前条件单限价有`限价需在当前 K 线高低点之外的限制`,移除这个限制
- 在图表上给条件限价单的辅助线右上方加入买入卖出、限价、数量的说明
- 条件单弹框中的买入卖出二选一改为一个单选器，并和限价、数量、持续时间放在一行上
- 移除条件单弹框中的`条件单设置`和`条件单列表`两个标题；条件单列表改为全量显示（当前为根据当前标的显示）

# 2.模拟盘资金管理和标的数量梳理
经过测试，当前资金管理的计算只适用于单个标的，选择多个标的时就会出现bug，所以现在重新梳理单个/多个标的、持仓记录、资金管理的关系

- 资金管理和持仓管理应该包含所有标的的统一计算
- 持仓记录中的当前价格是当前时间的对应标的的收盘价（现在是当前图表的当前价格）
- 所有的数据需要统一使用时间序列管理计算
