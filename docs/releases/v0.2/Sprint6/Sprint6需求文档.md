# 1.数据获取
- tushare提供接口`index_classify`可以获取申万行业分类2014和2021版本。我们考虑采用2021年版本——31个一级分类，134个二级分类，346个三级分类。
- tushare提供接口`index_member_all`。支持三个级别分类获取申万行业成分。可提供某个分类的所有成分，也可按股票代码提取所属分类。
- 要求这些数据入库：
  - 三级分类和分类关系
  - 分类和行业成分股的映射关系
- 股票反向查询行业分类：**采用新建表，不写 `stocks`，不运行时打 Tushare。**
  - ~~存入trading-zone.db内的stocks表~~（`stocks.industry` 是 stock_basic 扁平分类，和申万三级不是一套）
  - **另外新建表**（推荐）：`sw_industry` + `sw_industry_member`，放 `trading-zone.db`
  - ~~不在本地存储，直接通过tushare接口获取~~（选择器 / 面包屑是高频本地读；无筛选一次会被截断到 3000 行）
- 拉取约定（实测）：
  - `index_classify(src='SW2021')` 一次拿全树 511 行
  - 按 31 个一级循环 `index_member_all(l1_code, is_new='Y')`，合计 5902；本地 5562 只股票覆盖率 100%
  - 树的父子键是 `industry_code`，成员对齐的是 `index_code`（`.SI`），两套码不要混

# 2.功能实现
- 需要考察指数、股票能否区分？
- 股票列表上方的选择器拓展功能：
  - 当前是一个下拉单选菜单
  - 改成弹框，在当前`全市场、指数、成分股`这三种分类外，加入行业分类的选择，并且行业分类需要体现三级分类
- 股票的主窗格右上角区域加入板块三级分类的面包屑导航
