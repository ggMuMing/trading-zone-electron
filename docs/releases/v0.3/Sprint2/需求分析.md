# 深色模式

## 概述

- 为应用加入深色模式
- 在设置页面加入颜色模式切换，切换后当前已打开的页面整体换色，不刷新、不重载图表

## 做法

颜色模式只有 `light` | `dark`，缺省 `light`。存在 `localStorage` 键 `tz.colorMode`，和图表页面板宽度同一类本地偏好，不进数据库、不走 IPC。

渲染进程用一个 `ColorModeProvider` 包住应用，对外只暴露当前模式。下面三处读这同一个值：

1. MUI `ThemeProvider`：页面、对话框、表格、侧栏
2. 图表外壳色：lightweight-charts 画布，以及画在 K 线上的 HTML 浮层
3. Monaco：`vs` / `vs-dark`

设置页放一个「外观」区块，用两个按钮切换浅色 / 深色。点下去立刻写本地存储并更新上下文，不需要重启。

## 什么跟着换，什么不换

跟着换的是界面外壳：背景、文字、分割线、网格、坐标轴、十字线标签、图例底、图标按钮底。

不跟着换的是行情语义和用户自己选的颜色：

- 涨红 `#ef5350`、跌绿 `#26a69a`。K 线、买卖标记、涨跌家数继续用这一对
- 成交量柱 `#d27b2d`
- 指标样式里用户选定的颜色和线宽
- 买卖高亮带继续用涨跌色的 18% 透明。只有中性高亮带换：浅色 `rgba(0,0,0,0.08)`，深色 `rgba(255,255,255,0.10)`
- 颜色选择器的弹出层保持现在的深色工具面板。只把它的触发按钮改成跟页面走

浅色模式尽量保持现在的样子。仪表盘图表的文字和网格现在比 K 线更浅（文字 `#666666`、网格 `#f3f3f3`），统一后会略深一点，和 K 线对齐。

## 1. 应用整体

`main.tsx` 里现在写死 `mode: 'light'`。改成按模式生成主题：

| 令牌 | 浅色（维持现状） | 深色 |
|---|---|---|
| `primary.main` | `#1565c0` | `#64b5f6` |
| `background.default` | `#f5f7fa` | `#121417` |
| `background.paper` | `#ffffff` | `#1c1f24` |
| `text.primary` | MUI 默认 | `#e8e6e3` |
| `text.secondary` | MUI 默认 | `#a39e96` |
| `divider` | MUI 默认 | MUI 深色默认 |
| `error.main` | MUI 默认，不改 | `#ef5350` |
| `success.main` | MUI 默认，不改 | `#26a69a` |

深色把 `error` / `success` 钉在涨跌色上，这样模拟盘表格的红绿和 K 线一致。浅色不动这两色，避免现有表格变色。

侧栏、图表页布局、行情页、模拟盘、设置页、MUI 对话框已经用 `background.default`、`divider`、`text.secondary`，主题一换就会跟着走，不用逐个改。

`CssBaseline` 会带上 `color-scheme`，滚动条和原生控件一起变。

建议落点：

- `src/renderer/src/theme/colorMode.tsx`：上下文、本地存储、`ThemeProvider`
- `src/renderer/src/theme/chartChrome.ts`：下面第 3 节的外壳色
- `src/renderer/src/main.tsx`：用 Provider 换掉写死的 `createTheme`

设置页在 Token 区块上方加「外观」。

## 2. MUI 样式

大部分组件不用改。只改写死了黑白、不会吃主题的几处：

| 位置 | 现在 | 改成 |
|---|---|---|
| `IndicatorDialog.tsx` 选中行、悬停行 | `rgba(0,0,0,…)` | `action.selected` / `action.hover` |
| `StylePalette.tsx` 触发按钮 | 白底、黑边、`#333` 线标 | `background.paper`、`divider`、`text.primary` |
| `StylePalette.tsx` 弹出层内部 | 固定 `#2b2b2b` | 保持不动 |

模拟盘盈亏已经用 `error.main` / `success.main`，深色钉色之后自动对齐 K 线，组件本身不用再改。

## 3. lwc 样式

画布不读 MUI 主题。五处 `createChart` 都写死了白底：

- `pages/chart/KlineChart.tsx`
- `pages/dashboard/MiniKline.tsx`
- `pages/dashboard/StatCharts.tsx`
- `pages/dashboard/BreadthHistoryChart.tsx`
- `pages/dashboard/BasisProductChart.tsx`

外壳色集中成一份，浅色取现在 K 线的值：

| 用途 | 浅色 | 深色 |
|---|---|---|
| 背景 | `#ffffff` | `#1c1f24`（与 `background.paper` 相同） |
| 文字 | `#333333` | `#d0cdc8` |
| 网格 | `#eeeeee` | `#2a2e34` |
| 坐标轴边 | `#e0e0e0` | `#3a3f46` |
| 十字线 | `#9e9e9e` | `#6b7078` |
| 十字线标签底 / 字 | `#333333` / `#ffffff` | `#e8e6e3` / `#1c1f24` |
| 图例底 | `rgba(255,255,255,0.85)` | `rgba(28,31,36,0.88)` |
| 图例标签 | `rgba(0,0,0,0.55)` | `rgba(255,255,255,0.62)` |
| 图标字 | `rgba(0,0,0,0.45)` | `rgba(255,255,255,0.55)` |
| 图标按钮底 / 边 | `rgba(255,255,255,0.92)` / `rgba(0,0,0,0.22)` | `rgba(28,31,36,0.92)` / `rgba(255,255,255,0.22)` |
| 图标悬停底 | `rgba(0,0,0,0.06)` | `rgba(255,255,255,0.08)` |
| 仪表盘统计线 | `#1976d2` | `#64b5f6` |

图标悬停的橙色 `#ed6c02` 两种模式都保留。

图表只在挂载时 `createChart`。切换模式时对已有实例 `applyOptions`，不要把模式放进创建图表的 effect 依赖，否则可见范围、回放、十字线会被拆掉重建。

浮层是 HTML，盖在画布上，必须用同一份外壳色，否则深色 K 线上仍是白底图例：

- `PriceLegend.tsx`
- `SubpaneLegend.tsx`
- `LegendNameHoverBox.tsx`
- `ChartIconButton.tsx`
- `ReplayHighlightPrimitive.ts` 只换中性高亮

涨跌色现在在 `KlineChart.tsx`、`PriceLegend.tsx`、`dashboard/format.ts` 各写一份。收到 `dashboard/format.ts` 一处，两种模式共用。

## 4. 代码编辑器样式

`ScriptSourceEditor.tsx` 写死 `theme="vs"`。改成浅色 `vs`、深色 `vs-dark`。编辑器外框已经用 MUI `divider`，会跟着主题走。这一版不做自定义 Monaco 配色。

## 不做

- 不跟系统外观，也不做自动切换
- 不按页面单独配色
- 不改用户已保存的指标颜色
- 不把 `参考frontend/src/styles` 那套变量搬进来。当前界面以 MUI 令牌为主，那套是另一套产品的色板
