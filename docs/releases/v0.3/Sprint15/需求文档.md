# 1.基于图表的复盘功能
## 概述
- 该功能用于人工复盘功能。在图表页加入复盘功能，在右侧弹出复盘面板，复盘面板显示提前预设好的系统条件，对照图表给满足的条件打勾确认。
- 使用场景：每天拉取数据，然后选择标的组，对照系统条件和标的图表，分析是否符合系统条件

## 详情
- 在图表页面的工具栏加入复盘按钮，只在图表页加入，其他页的图表不加入这个功能
- 点击复盘按钮在右侧弹出复盘面板
- 复盘面板包括日历、交易系统条件表单
- 每支标的每个日期对应一条数据
- 交易系统表单包括：
  - 看多
    - 关键点：左侧关键点、无关键点、右侧关键点
    - 矩形：未形成矩形、矩形中（备注：接一个输入框：处于矩形的位置）、突破矩形 （备注：接一个单选：是否回踩矩形）
    - 波动率：坍缩、扩大
    - 成交量放大：是（备注：输入倍量）、否
    - 站上均线：5日、20日、60日、120日、250日
    - 是否符合2B法则：是、否
    - 板块零头羊效应：有（备注：指定标的）、无
  - 看空
    - 跌破底分型：是、否
    - 破位下跌：是、否
    - 高位放天量：是、否
    - 技术压力位：是、否（备注说明）
- 交易表单操作包含清空、保存，可以修改，修改并入保存操作中
