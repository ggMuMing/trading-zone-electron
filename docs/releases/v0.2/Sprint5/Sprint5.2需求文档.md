# 1. 统计格

- 在仪表盘「涨跌家数」分类**下方**新增分类：**基差**。
- 用 **2×2 四宫格** 按 **IH → IF → IC → IM** 展示四只中金所股指期货主力（用户口述末项为 IF，按对话品种补成 IM）。
- 每格一张图、**两个窗格**：
  - **上窗格**：主力收盘、对应现货收盘两条曲线。
  - **下窗格**：基差直方图。柱向上（基差为正）在柱**上方**标数值；柱向下（基差为负）在柱**下方**标数值。
- 日期窗口与两融 / 成交额 / 涨跌停曲线一致（查询 `start_date`–`end_date`，默认 `20240101` 至今天）。
- 无期货数据时该格为空，不挡涨跌家数。

# 2. 数据

- 现货收盘用已入库 `index_daily.close`，不新拉指数。
- 新拉 Tushare `fut_daily` **四条主力**收盘：`IH.CFX` / `IF.CFX` / `IC.CFX` / `IM.CFX`。
- 新表 `fut_daily`，只存 `ts_code, trade_date, close`；**不写入** `daily_bar` / `index_daily`。
- 基差查询时现算，不落库：

  `基差 = 现货收盘 − 主力收盘`

  正：现货升水（期货贴水）；负：现货贴水（期货升水）。柱的上下位置按正负。
- 挂在现有「更新数据」上（按日增量 + 窗口回填）；不新增配置按钮。

# 4. 不做

- 当月 / 次月 / 当季 / 下季、`fut_mapping`、结算价、年化贴水。
- 盘中实时、分钟线、IH 以外的期权 / 国债期货。
- 不改两融、成交额、涨跌家数选择器、左侧指数 K 线。
- 不把期货行情当图表页标的。
- 不改两融 / 成交额 / 涨跌停等其它仪表盘图例（备忘录「仪表盘图例」另项）。

# 5. 图例

- 四张基差图各自在**主窗格**（上窗格）叠一层图例，不放到下窗格。
- 三项：**期指价格**、**现货价格**、**基差**；系列名 + 数值。
- 默认显示最新一根；十字线指到哪日显示哪日；移出图区回到最新一根。
- 期指 / 现货用对应曲线色；基差用红 / 绿双色块，数字按正负着色（`>= 0` 红 `UP_COLOR`，负绿 `DOWN_COLOR`，与柱一致）。
- 无期货数据时该格仍为空，不渲染图例。
