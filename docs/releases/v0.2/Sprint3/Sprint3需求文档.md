# v0.2.3需求文档
## 一、改进指标弹框UI
- title改为指标与策略。字体加粗。
- 移除【当前布局】，当前指标的操作已经可以直接在图表上操作，不再需要在指标弹出框中操作
- 移除关闭按钮和尾部区域，关闭按钮设为右上角的“叉号”。新建脚本按钮改成“加号图标”放在指标title右侧
- 指标列表部分改为两列布局，左侧列分为`指标`、`策略`两项。右侧是具体的列表。列表的每一行去掉当前的时间只保留名称和key。添加编辑删除按钮改为对应的图标按钮，按钮需要title提示。鼠标在行中悬停时，加入悬停背景底色，另外悬停到图标按钮上时，按钮也需要突出。悬停样式可以和前面做的功能盒或者窗格右上角的功能按钮一致。
- 指标和策略为空时，需要给右侧的控件创建一个上方为图标下方为文字说明，整体横向居中和纵向剧中。
- 整个弹框固定宽高。列表超出部分用滚动条

## 二、改进指标设置弹框UI
- 缩窄弹框的宽度
- 右上角加一个关闭图标按钮
- `参数`分类改为grid两列布局。第一列是名称，第二列是输入框。输入框去掉title
- `样式`分类的布局调整
  - 改为grid布局，分为4列。第一列，是否显示的checkbox。第二列：图形名称。第三列：颜色。第四列：线宽。
  - 以macd为例的直方图。配置项是多个柱状图。采用下面方式：第一行，checkbox+图形成名，剩下两列空着。紧接着后面几行：checkbox列空着，名称+颜色。没有线宽
