# UI布局

- 调整 UI 布局。
- 采用两列布局。左侧为由图标构成的导航栏，右侧是具体页面。
- 整个页面固定高度为窗口可视高度。右侧页面高出可视高度的部分在专属页面内部滚动。

# 业务

当前迭代做两个页面：

1. 配置页面
2. 股票行情数据页面

- 添加两个图标导航

## 1.配置页面

- tushare pro 的 token 配置
- 股票数据信息：
  - 开始没有股票数据
  - 更新股票数据、清除所有股票数据功能
  - 显示数据起始日期、截至日期、股票条数等基本信息
  - 板块只数按 `stocks.market` + 交易所（`.SH` / `.SZ`）统计，不用代码前缀
- 更新数据逻辑：
  - 首次拉取与日常更新合并为一次「按窗口补齐」
  - 起始日本迭代锁死 `20240101`（仍作为入参下发）；截止日缺省今天、可改
  - 始终将 `start_date` / `end_date` 传给 Python；已 complete 的交易日跳过
  - 缩小截止日不删除已有数据
  - 追踪更新进度并展示
