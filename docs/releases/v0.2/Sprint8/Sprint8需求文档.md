# 两大主要模块
- 内置硬编码策略，生成买卖点
- UI图表可视化策略

# 需求分析
## 主要功能
在python端编写买卖点策略；在中间层管理策略业务；在前端图表复盘策略，在前端支持因子开关，因子参数调参。

## 功能拆分
### 1.python端编写策略
`Strategy.py`和`MingSystemVer1.py`，两个代码是测试性质的策略类

策略类需要的元素：
- 读取数据函数
  - 指定的标的、日期区间和其他限制的时间序列数据
  - 数据类型
    - 股票日线数据+复权因子
    - 大盘指数日线数据
    - 宽基指数日线数据
    - 期指主要合约日线数据
  - 提供给计算函数使用
- 计算函数
  - 数据由读取数据环节提供
  - 主要目的：
    - 计算指标
    - 打标签
      - 买卖点标签
      - 不匹配因子的失败原因标签（例如，不符合挤牌因子，打上对应的标签）
  - 输出：
    - 完整的包含整个时间序列的数据
    - 必须的数据项包括：
      - ohlcv
      - 时间
    - 可选的：计算过程中产生的数据
- 分析结果
  - 用来对计算结果做统计分析的函数
  - 返回一个统计分析结果的对象
  - 先创建一个最小统计数据占位：买入信号数量和总K线数
- 输出结果
  - 将统计分析过的数据输出给中间层
  - 标准化输出
    - 拼接返回对象：将计算输出的带有标签的序列化数据和分析结果得到的分析结果对象拼接返回

### 2.electron中间层
- 在代码中保存策略的映射
- 获取策略的接口
- 执行策略的接口
  - 入参：标的、日期区间、复权
  - 匹配策略，执行策略
  - 返回：统计数据和序列化数据

### 3.UI图表
#### 3.1 `策略面板`
选中策略，打开`策略面板`：
- `图表`页面的指标的`指标与策略`弹框预留了策略分类
- 调用接口，加载策略列表，策略列表每一行加入`加号`图标按钮
- 点击`加号`按钮，关闭弹框。在图表右侧加入一个从右展开的新panel面板，命名为`策略面板`。它区别于脚本编辑器那种z-index覆盖在图表上，它是和图表、标的列表平级的面板
- `策略面板`占据整个高度，支持通过拖拽改变宽度，最大宽度不能超过整个图表可视区域的一半（不包含标的列表）
- 选择`策略`是单选的，选中后再打开策略弹框，策略列表上，被选中的策略背景底色加深，图标变为`正确`，不能点击。其他策略的`加号`图标变为`切换`图标，点击意味切换了策略

`策略面板`内部:
- **顶部面板栏**：标题+关闭按钮。
  - 标题：“选中的策略名”
  - 关闭按钮：点击关闭，取消策略选中，删除面板
- **面板栏下方**：起始时间选择器+结束时间选择器+`执行`图标按钮
  - 起始时间选择器+结束时间选择器：选择时间间隔
  - `执行`图标按钮：点击调用接口执行策略，获取结果
- **统计结果**
  - 根据返回的键值对，采用横向的`键（加粗）：值`的布局显示一对数据。
  - 每一行显示几个键值对需要自适应面板宽度，列方向要求键值对占宽要自适应一致对齐
- **序列化数据列表**
  - 这一模块是本次迭代UI部分的交互核心
  - *第一部分，Tabs组件*：包含4个Tab：`买点`，`卖点`，`买卖混合`，`自选数据`。Tab内部包含对应的数据列表。
  - *第二部分，所有Tab的公共操作按钮*：这些操作按钮用于`复盘模式`：在数据列表中切换选中的K线，并在图标上高亮显示，以此达到复盘的目的
    - 操作由五个`图标按钮`组成，由左到右：
      - 上一根K线：切换到列表中的上一条K线，没有开始和第一根K线，该按钮不可用
      - 刷新按钮：回到第一根K线，没有开始该按钮不可用。
      - 开始按钮：开始`复盘模式`，选中第一条数据，图表上开始高亮模式。点击开始按钮后，按钮变为取消按钮。
      - 取消按钮：退出`复盘模式`，图表退出高亮模式。点击取消按钮后，按钮变为开始按钮。
      - 下一根K线：切换到列表中的下一条K线，没有开始和最后一根K线，该按钮不可用。
  - *第三部分，列表本体*
    - 列表通用部分：列选择器，日期、ohlcv、买点、卖点是必选列，其他字段通过数据读取出来，列为可选项，缺省不选
    - 列表通用部分：列表交互，默认状态下，纯列表模式；开始`复盘模式`，被选中的行用背景色强调，除了按钮操作，支持直接点击选中。按钮操作切换下一条K线，如果K线在可视区外面，自动滚动滚动条，保证这条数据显示在可视区的底部
    - 所有列表默认按时间降序排列，加入切换时间排序功能，也就是说可以切换成升序排列
    - 买点tab：只显示买点数据
    - 卖点tab：只显示卖点数据
    - 买卖混合tab：按时间显示所有买卖点数据
    - 自选数据：在操作按钮上面加入开始+结束时间选择器+查询按钮。过滤出的数据是不区分买卖点和未命中的全数据

#### 3.2 图表交互
- 策略`执行`返回结果后，根据结果在买点K线的下方加一个红色的图标标识，在卖点K线的下方加一个绿色的图标标识。图表组件需要加入标识的支持。
- 策略开启`复盘模式`,图表进入`高亮模式`,被选中的K线在主图上，这一根K线宽度的整个高度填满高亮色背景。高亮色遵循不能对K线喧宾夺主的原则，根据K线类型：卖点：浅绿色；买点：浅红色；非买点：浅灰色。
- 策略结束`复盘模式`，图表一并退出`高亮模式`
