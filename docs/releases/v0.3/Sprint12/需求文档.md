# 1.模拟记录数据面板
## 概述
- 创建数据面板为模拟记录提供更详细的数据分析功能
- 通过迭代让数据面板可以提供包括图表、数据分类、更详尽的数据、数据分析等功能

## 详情
### 1.入口
- 模拟记录Tab下，在交易记录标题行的最右侧加入一个图表按钮，这个按钮就是打开数据面板的入口，在模拟记录列表中点击名称并选中了某一条模拟记录，这个按钮变为可用，点击该按钮打开一个全屏弹框，这个弹框即模拟记录的数据面板

### 2.数据
**1.基础数据和图表**
- 初始资金、结算资金、总收益率
- 交易笔数、获胜笔数、失败笔数、胜率——使用清仓盈亏计算胜负
- 资金变化数据
  - 资金曲线图，右侧加一个收益率坐标轴，以初始资金为零轴
  - 叠加一个副图：收益率柱状图
  - 最大回撤
- 持仓变化数据
  - 持仓金额曲线图+仓位百分比直方图，仓位最大100%
