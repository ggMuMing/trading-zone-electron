# 目标一：脚本优化
## 1. 参数声明
- 当前版本的脚本参数声明参数和类的属性混在一起，建议给Indicator类加一个函数专门用来声明指标参数，在执行这个类的时候，调用这个函数获取参数。
- 当前声明参数的方式`period1:int = Field(default=5, ge=1, json_schema_extra={"widget": "int", "title": "周期1"})`,非常不优雅
  - 建议参考pinescript的函数模式：`int lengthInput = input.int(10, "Length", 1)`
  - pine的input函数功能很多，并且依赖于pinescript的type system(https://www.tradingview.com/pine-script-docs/language/type-system/#introduction)。我们当前版本只需要支持最基础的类型："int、float、boolean"
  - int、float类型入参有`缺省值、title、最大、最小值`
  - bool类型入参有`缺省值 true/false、title`

## 2.可配置项隐式化
- 当前版本，线宽、颜色和参数一样都是显式声明的，首先这种声明方式很复杂，其次很多余，完全可以在输出的函数里面将这些值识别为可配置项

## 3.输出函数
当前输出方式:
```
def compute(self, ohlcv: Ohlcv) -> PlotFragment:
    return overlay(
        line(
            f"ma{self.period1}",
            sma(ohlcv.close, self.period1),
            times=ohlcv.time,
            color=self.color1,
            line_width=self.lineWidth1,
        ),
    )
```

- 在`compute`函数中计算和输出这个逻辑没有问题可以保留
- 在pinescript中，输出只需要`plot(high, PLOT1_TITLE)`就完成了，所有的输出逻辑放在plot里面
- 我们的系统在编写脚本时需要显式地调用overlay函数，并且输出时是是调用`line`等函数，传参还包含了声明的颜色变量、线宽变量，而不是一个常量。
- 综上所述，我们在输出时可以保留在compute函数中完成逻辑，需要思考如何参考pinescript实现方式
