# 参数定义

# 买点
## 1.波动坍缩
- 目标：波动率坍缩到比较低的水平
- 判断方法：布林通道收窄到肯特那通道
  - 变量`M`:缺省20
  - 布林通道：`MA_M ± 2*STD`
  - 肯特那通道：`MA_M ± C*ATR_M`
- 公式表达: `MA_M ± 2*STD < MA_M ± C*ATR_M` -> `2*STD < C*ATR_M`

## 2.动量
### 2.1 大周期看价格行为
- 目标：价格在大周期上已经到达强势区域
- 判断方法：威廉指标小于50。
  - 变量`N`:缺省10
  - 价格来到N日最大最小值波幅的上半区
- 公式表达：WR_N < 50

### 2.2 小周期看单根K线形态
- 目标：找到涨幅很强的K线
- 判断方法：K线的涨幅达到过去几天的波幅
  - 变量`W`:缺省5
  - 变量`C-O` || `C-L`：计算涨幅
  - 波幅比例`K1`:缺省0.6
公式表达：`C-O >= (high_W - low_W) * k`

## 3.成交量
- 目标：放量上涨
- 判断方法：计算成交量比值
  - 比值系数`K2`
  - 成交量平均周期`R`
- 公式表达：`V >= MAV_R * K2`

# 卖出
## 1.止损
- 收敛通道的最低点
  - 需要量化通道波幅大小
  - 窄幅通道用最低点
- 强势K被否定：最低价跌穿强势K起点
  - anchor = open || low
  - stop = anchor - K2 * scale
  - K2：缺省0，scale：强势K前面`W`天的波幅
- W天最低点
- 超时：满D根，收盘价仍小于等于买入价
