Sprint5：指数成分股的获取和展示
___

# 1. 数据获取

- 获取统计仪表盘中 **14 只展示指数** 的成分股（见 `DASHBOARD_DISPLAY_INDICES`）
- 主接口：`index_weight`（Tushare，2000 积分；月度快照）
- **统一表** `index_weight` 入库：`index_code`、`trade_date`（月末快照日）、`con_code`、`weight`
- 按月保存一份最新快照；**不回填** 202401 起历史月份
- 不拉成交量替身指数（`399107.SZ` / `399102.SZ`）

# 2. 功能

## 2.1 更新数据

- 配置页新增 **「更新成分股」** 按钮，与 **「更新数据」** 区分
- 按**月**更新；门控看库里是否已有**最近可得月末快照**（非「当前自然月有没有行」——月初当月接口常为空，应保留上月）
- 当月有数据则 upsert；当月空且尚无上月快照时再拉上月；已有则 skip

## 2.2 图表页选择器

- 将 `股票（5562 / 5562）` 换成分组选择器，切换后列表与选中标的变为该宇宙**第一项**
- **全市场**：全部 A 股列表 + 个股日线（`daily_bar`，复权可用）
- **指数行情**（指数作为标的，看指数日线 `index_daily`，复权禁用）：
  - **大盘指数**：上证指数、深证成指、创业板指、科创综指、北证50
  - **宽基指数**：上证50、科创50、创业板50、沪深300、中证500、中证1000、中证2000、中证A50、中证A500
- **成分股**（14 只具体指数各一项）：该指数最新成分列表 + 个股日线；无数据时提示到配置页更新成分股

## 2.3 不做

- MarketPage 选择器、权重展示、按日成分、历史回填、一指数一表、改仪表盘三格
