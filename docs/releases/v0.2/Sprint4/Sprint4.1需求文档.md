v0.2.4-1 仪表盘改进
___

# 1.修改布局
- 4宫格改为：左侧上下布局共两个格子，右侧单独一个格子占整个高度。
- 默认宽高
  - 横向两边各占1/2
  - 左上方高度占3/4
  - 左下方高度占1/4
- 可调节宽高范围
  - 横向最小宽度为1/4
  - 左上方高度在1/2~3/4之间
  - 左下方高度在1/4~2/3之间
- 格子中的内容变化
  - 左上方放K线
  - 左下方放指数列表
  - 右侧放统计数据

# 2.功能调整
- K线图方格标题行加入数据截止日期
- 指数列表的涨跌幅列加入排序功能
- 统计方格调整
  - 两融余额的曲线图和变化的直方图应该采用和图表视图中的K线图一样——单图表多窗格的模式对齐横坐标的日期
  - 两融余额line图的图例用描述+颜色线的形式，不要用单文字说明
  - 成交额和两融余额一样单图表多窗格对齐日期
