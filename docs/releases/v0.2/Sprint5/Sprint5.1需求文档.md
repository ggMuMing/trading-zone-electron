# 1. 统计格

- 在仪表盘「涨跌家数」标题行**右上角**增加选择器：**全市场、沪深300、中证2000**。
- 切换后，**当日四数**（上涨 / 涨停 / 下跌 / 跌停）、**九档柱状图**、**涨跌停历史曲线**三块同步按所选集合重算。
- 默认「全市场」，行为与 Sprint4 / Sprint4.2 一致。
- 无该指数成分快照时，四数 / 九档 / 曲线为空，提示「尚无成分股数据，请到配置页更新成分股」。

# 2. 数据

- 不新拉 Tushare；涨跌停状态仍用已入库的 `stock_limit_status`，过滤规则与 Sprint4 相同（与 `daily_bar` 同日 JOIN，且 `vol > 0`）。
- 沪深300 / 中证2000 用 Sprint5 已入库的 `index_weight` **最新一条月末快照**过滤成分股；整段历史曲线也用同一份最新快照（不按历史月份回溯）。
- 指数代码：`000300.SH`（沪深300）、`932000.CSI`（中证2000）。

# 3. 不做

- 不加其他宽基、不做权重展示、不下钻个股、不做盘中实时。
- 不改两融 / 成交额 / 左侧指数 K 线；选择器不持久化。
- 不改「更新数据 / 更新成分股」同步路径。
