# 图表画图功能

## 库里有什么

当前图表用的是 lightweight-charts 5.1。它没有画线工具：没有趋势线、水平线、矩形的创建接口，也没有选中、拖拽、端点、撤销。

能用来自己画的是这几块：

| 接口 | 作用 | 够不够当画线工具 |
|---|---|---|
| `series.attachPrimitive` / `ISeriesPrimitive` | 在序列的画布上自绘。缩放、平移时库会调 `updateAllViews`。`hitTest` 能回报鼠标下的对象 id，点击和十字光标事件里用 `hoveredObjectId` 读到 | 画线应挂在这里 |
| `pane.attachPrimitive` / `IPanePrimitive` | 挂在某一窗格上，不绑定序列。回调里只有 chart，没有价格坐标换算 | 适合水印，不适合跟价格走的线 |
| `series.createPriceLine` | 一条水平价格线，可带坐标轴标签 | 不能点选、不能拖。只覆盖水平线，不拿它当画线模型 |
| `DrawingUtils.setLineStyle` | 在 primitive 的 canvas 上设虚线样式 | 只是画笔辅助 |
| `subscribeClick` / `subscribeCrosshairMove` | 给出 `point`、`time`、`logical`、`paneIndex` | 落点用这些 |
| `timeToCoordinate` / `coordinateToTime` | 日期和横坐标互转。`coordinateToTime` 落到某根 K 线 | 锚点的时间 |
| `priceToCoordinate` / `coordinateToPrice` | 价格和纵坐标互转，跟蜡烛序列的价格轴走 | 锚点的价格 |
| `logicalToCoordinate` / `coordinateToLogical` | 逻辑下标（可以落在两根 K 线之间）和横坐标互转 | 需要亚 K 线精度时再用 |

买卖高亮带已经是一个 series primitive：`ReplayHighlightPrimitive` 挂在蜡烛序列上，用 `drawBackground` 画竖带。画线和它是同一类扩展，不是新的图表通道。

`ChartInput.primitives` 是指标线（MA、MACD），名字容易和 LWC primitive 混。画线不进这份通道，也不进 Python。

## 初步方案

画线是用户在某只股票上标的几何，不是指标。按 `ts_code` 存在 SQLite，换股切换，重启还在。不进布局表（布局是全局指标实例），不进 `localStorage`（那是颜色模式这类界面偏好）。

坐标只存「日期 + 价格」，不存像素。日期吸附到最近一根 K 线的 `time`，价格用 `coordinateToPrice` 的原值。平移、缩放、换复权后的重绘都用 `timeToCoordinate` 和 `priceToCoordinate` 现算。复权切换会改变价格，第一版画线跟当前图上的价格走，不单独存复权类型。

第一版只画在主图，并且只做三种：

| 工具 | 锚点 | 操作 |
|---|---|---|
| 水平线 | 一个价格 | 点一次完成 |
| 趋势线 | 两个「日期 + 价格」 | 点第一次定起点，移动时出预览，点第二次完成 |
| 矩形 | 两个对角「日期 + 价格」 | 同趋势线 |

副图点击忽略。文字、射线、通道、斐波那契、磁吸高低点、撤销，这一版不做。

交互分两态：

1. **画。** 工具栏选中工具后，关掉图表的拖拽平移（`handleScroll`），避免第一笔被当成平移。水平线一次点击落成；两点工具用十字光标移动画预览，第二次点击落成。完成后回到浏览态，平移恢复。
2. **改。** 浏览态下 `hitTest` 命中线或端点时，`hoveredObjectId` 选中它。拖端点期间同样暂时关掉平移。Delete 删除选中图形。没有单独的撤销栈。

渲染上主图只挂一个 primitive，里面画全部图形和正在画的预览。`hitTest` 返回图形 id 或端点 id。不要每种图形各挂一个 primitive，否则命中顺序和现有高亮带叠在一起难管。价格轴标签第一版不画，水平线只在图内。

数据形状：

```ts
type DrawingPoint = { time: string; price: number }

type ChartDrawing =
  | { id: string; kind: 'hline'; price: number; color: string; lineWidth: 1 | 2 | 3 | 4 }
  | { id: string; kind: 'trend'; a: DrawingPoint; b: DrawingPoint; color: string; lineWidth: 1 | 2 | 3 | 4 }
  | { id: string; kind: 'rect'; a: DrawingPoint; b: DrawingPoint; color: string; lineWidth: 1 | 2 | 3 | 4 }
```

建议落点：

- `src/shared/types/chartDrawing.ts`：上面的类型
- SQLite 表 `chart_drawing(ts_code, id, kind, payload)`，payload 是单条图形的 JSON。走现有 Renderer → IPC → SQLite
- `src/renderer/src/pages/chart/drawings/`：primitive、工具状态（浏览 / 等第一点 / 等第二点 / 拖端点）
- `KlineChart.tsx`：把 primitive 挂到蜡烛序列上，订阅点击和十字光标。图例用的 `subscribeCrosshairMove` 继续留着
- 图表页工具栏加三个工具按钮和删除

换股时按 `ts_code` 重载列表并 `requestUpdate`。图被拆掉重建时，primitive 随蜡烛序列一起卸下再挂上，几何数据留在表里。

## 移动缩放
### 原则
1.点击选中图形，光标拖拽到目标位置，中间需要图形跟随光标的移动过程，而不是当前的光标在拖拽，松开光标，图形跳转到光标松开时的位置。涉及：水平线在纵轴上的移动、趋势线平面的移动、趋势线的缩放、趋势线的调整角度、矩形的缩放

### 新增/调整功能
1.选中趋势线后，趋势线在平面上的整体平移。这和图表的拖拽移动K线图会冲突，需要解决这个冲突，趋势线的拖拽不能冒泡到外层的图表
2.选中矩形后，矩形在平面上的整体平移。和趋势线相同的情况
