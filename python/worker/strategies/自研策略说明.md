# 目标：寻找短线波段起点的关键K
# 滤网
## 一、周期
- 在波幅缩小周期中寻找波幅扩大的信号：使用布林带和KC带的挤压，布林带收窄于KC带判断当前波幅小。
- 用数学公式表示：`20周期的标准差STD小于20周期的ATR`

## 二、动能穿透
### 1.使用威廉指标
- 威廉指标公式：`WR=(Hn-C)/(Hn-Ln)*100`；n缺省取6
- 从公式可得：分母`过去N天的最高值和过去N天的最低值`代表的最近N天的波幅是相对固定的，WR的值主要由C和Hn决定。C是关键变量。
  - 当C越小于Hn时，Hn-C越大，WR的值也越大；C越接近Hn，WR越小
  - 当C大于等于H_(n-1)时,C就是Hn本身，WR等于0

从公式可以得出C越高，WR越小，代表多头越强

- **使用WR小于50**，即收盘价C相对于Ln的涨幅超越了过去N天的最高最低价波幅的一半

### 2.必须是强势K
WR小于50只能说明收盘价格累积了一定的涨幅，它可能是：
- 连续几根小碎K线推高的价格
- 一根实体很大的K线推高的价格

从K线和价格行为上，后者比前者强的多，所以这一层过滤要筛选出强势的K线

这里继续和`Hn-Ln`的波幅做比较，但是采用两种不同的波幅做对比
- C-O:收盘与当天开盘的波幅。
  - 忽略下影线，开盘价上方做多动能够强才能被选中
- C-L:收盘与当天最低价的波幅
  - 接受比较长的下影线，只要最低价到收盘价的做多动能强就能被选中

对于哪一种更优，需要回测判断

最后，为`Hn-Ln`的波幅加入一个系数`k`(缺省为1),得到公式：
```
C-O(或者C-L) = (Hn-Ln)*k
```

## 三、成交量配合
- 当日成交量大于等于过去x天成交量平均值的y倍
- x缺省为5，y缺省1.5

# 卖出
## 止损
- `O - (Hn-Ln) * z`
- z为系数，缺省1.2

## 止盈
- 记录信号k位置的与20日均线的标准差s1
- 后续K线价格向上产生浮盈，收盘价与20日均线的标准差记为s2
- 当s2 = w * s1时卖出

# 参数管理
- 过去n日波幅：n缺省6
- 信号K波幅范围：C-O || C-L
- 波幅系数K：缺省0.6
- 成交量平均x天：缺省5
- 成交倍量y：缺省1.5
